# lidar — робот для аэропорта

Четыре независимых направления в одном репозитории:

```
lidar/
├── arduino/      # прошивка Mega, моторы, энкодеры
├── lidar_map/    # проезд: лидар, карта, веб-пульт, A→B, админ-панель
├── camera/       # умная камера: USB лицо + центр (Tapo позже)
└── monitor/      # экран пассажира: киоск, 6 кнопок, билет, карта регистрации
```

| Папка | Задача | Не трогает |
|-------|--------|------------|
| `arduino/` | шасси, teleop bridge | камеру, карту, монитор |
| `lidar_map/` | ROS-карта, навигация, `:8765` | камеру, монитор |
| `camera/` | RTSP, детект лица, удержание в центре | проезд, монитор |
| `monitor/` | сенсорный UI, 6 главных кнопок, скан билета | проезд, камеру |

Запуск направлений — раздельно (свои скрипты / README внутри папок).

## Адреса на роботе

Подставьте IP робота (часто `10.255.210.201`):

| Что | URL |
|-----|-----|
| Карта / телеоп | `http://<robot>:8765/` |
| Пассажирский киоск | `http://<robot>:8765/kiosk` |
| **Админ-панель** | `http://<robot>:8765/admin` |
| То же (алиасы) | `/operator-panel`, `/panel`, `/admin-panel` |

## Админ-панель — как открыть и пользоваться

Админ-панель — веб-консоль оператора. По умолчанию **простой режим** (автодиагностика), полный — по кнопке.

### Открыть с ноутбука (рекомендуется)

1. Робот в той же сети, стек `:8765` запущен.
2. В браузере откройте:

```text
http://10.255.210.201:8765/admin
```

Или двойной клик / запуск:

```bat
lidar_map\start_admin.bat
```

(по умолчанию открывает `http://10.255.210.201:8765/admin` в Edge/Chrome app-окне; IP можно переопределить: `set ROBOT_API=http://<ip>:8765`).

Локальный прокси (если удобнее `127.0.0.1`):

```bat
python lidar_map\admin_local_server.py
```

Затем: `http://127.0.0.1:8878/admin` (проксирует API на робота).

### Режимы

**Простой** (по умолчанию):
- чипы статуса: связь, лидар, одометрия, процессы, навигация, score карты;
- автообновление каждые ~2 с;
- **Автопочинка** — СТОП + health/analyze;
- сохранить / freeze карты;
- ссылки на киоск и карту;
- кнопка **СТОП**.

**Полный** (кнопка «Полный» в шапке):
- езда (телеоп), цель A→B;
- миссия по waypoints;
- аэропорт: escort / билет;
- iframe карты и киоска;
- логи, произвольный API.

### Что должно быть запущено на Pi

```bash
# лидар + карта + drive (пример)
bash ~/robot_nav/lidar_map/start_drive_map.sh
```

Проверка:

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8765/admin
# ожидайте 200
```

## Киоск на мониторе робота (не на ноутбуке)

Киоск нужно показывать на экране Pi:

```bash
bash ~/robot_nav/monitor/start_kiosk_on_robot.sh
```

Или ярлык **«Киоск на мониторе робота»** на рабочем столе Pi (`monitor/start.desktop`).

Полный старт монитора (может перезапустить web UI):

```bash
bash ~/robot_nav/monitor/start
```

Быстрый старт стека (лидар + web + камера):

```bash
bash ~/lidar/lidar_map/start_kiosk_stack.sh
```

Кнопки киоска: `monitor/primary_buttons.json`.

## Полностью локальная работа (без интернета)

1. Ноутбук и Pi в одной LAN.
2. Деплой с ноута:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\local-deploy-pi.ps1 -PiHost 10.255.210.201
```

Скрипт пакует `lidar_map/` + `monitor/` (и `camera/` при наличии), копирует на Pi в `~/robot_nav/`, перезапускает стек.

После деплоя:
- админ: `http://<pi-ip>:8765/admin`
- киоск на мониторе Pi: `bash ~/robot_nav/monitor/start_kiosk_on_robot.sh`
