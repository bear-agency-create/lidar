# lidar — робот для аэропорта

Три независимых направления в одном репозитории:

```
lidar/
├── arduino/      # прошивка Mega, моторы, энкодеры
├── lidar_map/    # проезд: лидар, карта, веб-пульт, A→B
└── camera/       # умная камера: USB лицо + центр (Tapo позже)
```

| Папка | Задача | Не трогает |
|-------|--------|------------|
| `arduino/` | шасси, teleop bridge | камеру, карту |
| `lidar_map/` | ROS-карта, навигация, `:8765` | камеру |
| `camera/` | RTSP, детект лица, удержание в центре | проезд, Arduino |

Запуск направлений — раздельно (свои скрипты / README внутри папок).
