# lidar — робот для аэропорта

Четыре независимых направления в одном репозитории:

```
lidar/
├── arduino/      # прошивка Mega, моторы, энкодеры
├── lidar_map/    # проезд: лидар, карта, веб-пульт, A→B
├── camera/       # умная камера: USB лицо + центр (Tapo позже)
└── monitor/      # экран пассажира: киоск, 6 кнопок, билет, карта регистрации
```

| Папка | Задача | Не трогает |
|-------|--------|------------|
| `arduino/` | шасси, teleop bridge | камеру, карту, монитор |
| `lidar_map/` | ROS-карта, навигация, `:8765` | камеру, монитор |
| `camera/` | RTSP, детект лица, удержание в центре | проезд, монитор |
| `monitor/` | сенсорный UI, 6 главных кнопок, скан билета | проезд, камеру |

Запуск направлений — раздельно (свои скрипты / README внутри папок).

Быстрый старт на роботе (лидар + web + камера):

```bash
bash ~/lidar/lidar_map/start_kiosk_stack.sh
```

На роботе:
- пульт оператора/карта: `http://<robot>:8765/`
- пассажирский киоск: `http://<robot>:8765/kiosk`

Кнопки настраиваются в `monitor/primary_buttons.json`.

## Полностью локальная работа (без интернета)

Если роутер без выхода в сеть, работай так:

1. Ноутбук и Pi в одной LAN.
2. Деплой текущего кода прямо с ноута на Pi:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\local-deploy-pi.ps1 -PiHost 10.255.210.201
```

Скрипт:
- пакует `lidar_map/`, `monitor/` (и `camera/`, если есть),
- копирует архив на Pi по SSH,
- распаковывает в `~/robot_nav/`,
- перезапускает стек.

Локальные адреса управления:
- оператор/лидар: `http://<pi-ip>:8765/`
- монитор/киоск: `http://<pi-ip>:8765/kiosk`
